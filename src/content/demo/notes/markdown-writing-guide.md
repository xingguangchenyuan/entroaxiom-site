写学习笔记最怕两件事：格式记不住，图片放不进。这篇把本站正文支持的格式过一遍，图片部分用两张示例图演示。

## 标题与正文

正文用 `##` 与 `###` 分层即可，本站会自动为两级标题生成阅读目录。段落之间用空行分隔，段落首行不缩进。

## 引用与链接

> 引用块用于摘录原文。链接写法：本站用 [markdown 指南](https://www.markdownguide.org/) 或直接贴出 `https://example.com`。

外部链接会在新标签页打开，长链接会自动换行，不会撑破版面。

## 表格

表格在笔记本里记录对比项非常顺手：

| 语法 | 用途 | 常用程度 |
| --- | --- | --- |
| `#` ~ `######` | 标题 | ★★★★★ |
| `**粗体**` | 强调 | ★★★★ |
| `*斜体*` | 书刊名 | ★★★ |
| `` `代码` `` | 行内代码 | ★★★★★ |
| `> 引用` | 摘录 | ★★★ |
| `- 列表` | 无序列表 | ★★★★★ |
| `1. 列表` | 有序列表 | ★★★ |
| `[文字](url)` | 链接 | ★★★★★ |
| `![alt](url)` | 图片 | ★★★★ |
| `---` | 分割线 | ★★ |

## 代码

行内代码用于单个符号：`const x = 1`。多行代码用围栏代码块：

```
// 本站代码块：等宽字体、浅底、横向滚动，不做语法高亮
function hello(name) {
  return `Hello, ${name}`;
}
```

掌握了以上格式，就能写出结构清晰的笔记。复杂排版（比如流程图）超出纯 Markdown 的范围时，建议直接写成文字段落，保证任何设备都可读。
